# Affiliate E-Commerce Website

A complete frontend-only e-commerce platform for affiliate products with admin panel, designed to work on GitHub Pages.

## Features

- **Frontend Only**: No backend required - works entirely in the browser
- **Admin Panel**: Secure admin area with login system
- **Product Management**: Add, edit, delete affiliate products
- **Bulk Upload**: Import multiple products via JSON
- **Philippine Peso**: All prices in PHP currency (₱)
- **Responsive Design**: Works on all devices
- **Local Storage**: Data persists between sessions

## Setup for GitHub Pages

1. **Upload all files** to your GitHub repository
2. **Enable GitHub Pages** in repository settings
3. **Access your site** at `https://yourusername.github.io/repository-name`

## Local Development

1. **Download all files** to a folder
2. **Open `index.html`** in a web browser
3. **No server required** - runs completely in the browser

## Admin Access

- **Username**: `admin`
- **Password**: `password123`

Click "Admin Login" in the navigation to access the admin panel.

## Features Overview

### For Customers:
- Browse products by category/source (TikTok, Amazon, etc.)
- View product details in modal
- Click affiliate links to purchase
- Filter products by source

### For Admins:
- Add new products with forms
- Edit existing products
- Delete products (soft delete)
- Bulk upload products via JSON
- Manage all products in one place
